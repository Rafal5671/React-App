## Description

MobileStoreApp is a mobile application for an online store, developed using **React Native** with **Expo**. It provides users with a simple interface to browse products, view details, and manage their shopping cart. The app supports Android, iOS (via simulator), and Expo Go for testing.

The project demonstrates mobile development practices including component-based architecture, hooks, context API, and navigation.

---

## Features

* Browse and view product listings
* Product details and descriptions
* Shopping cart management
* User-friendly mobile interface
* Supports Android and iOS platforms
* Built with React Native components and Expo tools

---

## Technology Stack

* **Frontend:** React Native, TypeScript
* **Framework:** Expo
* **State Management:** React Context and Hooks
* **Routing & Navigation:** React Navigation
* **Styling:** CSS-in-JS / StyleSheet
